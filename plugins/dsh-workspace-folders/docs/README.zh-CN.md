# 工作区文件夹

为每个 DeepSeek Harness 工作区添加多个文件夹，在 Agent 对话中一起使用。

[English](../README.md)

<!-- release-state-note -->

## 做什么

- 在工作区菜单中增加 **文件夹…** 入口。
- 在同一弹窗中展示固定的主文件夹，并管理附加文件夹。
- 每个工作区分别保存文件夹列表，供其中的对话共用。
- 将文件夹列表提供给 Agent，并纳入工作区可写范围，继续遵循会话当前的权限模式。

## 安装

插件目前处于本地开发阶段。在仓库根目录构建并安装本地包：

```sh
pnpm --filter @klarkxy/dsh-workspace-folders build
dsh plugin --profile web add ./plugins/dsh-workspace-folders
```

重启目标配置后启用插件。运行环境要求见 [package.json](../package.json)。

## 使用

1. 打开工作区的 **⋯** 菜单，选择 **文件夹…**。
2. 选择 DSH 所在机器上的文件夹，或输入其绝对路径。
3. 添加或移除附加文件夹，点击 **保存**。点击 **取消** 放弃本次修改。

修改从下一轮对话生效。主工作目录保持不变，命令和相对文件路径仍以它为起点。需要使用附加文件夹时，可以直接在对话中告诉 Agent 文件夹名称或绝对路径。

从列表移除文件夹会保留磁盘上的文件。重新打开弹窗即可查看已保存的列表。

## 主要限制

- Web 界面管理的是 DSH 宿主机器上的目录，远程连接时也一样。选择的文件夹须在该机器上存在且可访问。
- 只读会话继续保持只读，其他宿主审批和沙箱规则照常生效。
- 附加文件夹提供工作上下文和文件访问；项目配置与指令文件的自动发现仍跟随主项目。
- 已启动的进程保留启动时的权限；文件夹列表的修改用于后续回合。

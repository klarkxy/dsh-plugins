# 模型枢纽

<!-- release-state-note -->

[English](../README.md)

在一个页面查看并修改各 DeepSeek Harness 插件使用的模型，管理子代理可用的模型，并跟踪运行中子代理的模型与思考强度。

## 安装

```sh
dsh plugin --profile web add @klarkxy/dsh-model-hub
```

把 `web` 换成你的 profile 名，安装后重启 profile。

## 使用

打开「插件 → 模型枢纽」。

- **字段总览**：列出已安装插件提供的模型设置，例如自动标题、Git 提交和安全自动。可按插件、用途或当前模型搜索，再选择新模型；改动由对应插件保存。
- **子代理阵容**：开关子代理模型白名单，添加、替换或移除模型。开启且至少有一个模型时，会引导智能体发现当前会话可用的模型，并在派发时显式选择。独立复核和方案对比会优先考虑合适的不同模型，同模型更适合时仍可使用。自填的模型「任务倾向」只作可选参考，插件不预置任何倾向。列表下方实时显示运行中的子代理及其当前模型和思考强度；标注「适配器默认」的强度来自适配器，而非显式选择。

## 限制

- 只显示提供模型设置的插件。
- 别处改动设置时页面自动更新；编辑与较新的改动冲突时，刷新后重新选择。
- 模型列表读取失败时点「重试」。上次可用的列表保留；部分提供方读取失败会显示提示，其余提供方仍可用。
- 选模引导需要宿主工具支持选择子代理模型。名单修改对新建会话生效，已有会话及其子代理沿用原名单；刷新设置页面不会更新会话名单。不显式指定模型时仍可继承父代理模型。
- 引导不强制选模，也不为增加模型种类而新增子任务。
- 远程子代理和已结束的子代理没有可读取的路由；运行列表只覆盖存活的本地子代理。
- 不提供用量统计。

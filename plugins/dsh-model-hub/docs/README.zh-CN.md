# 子代理

<!-- release-state-note -->

[English](../README.md)

配置新建 DeepSeek Harness 子代理可用的模型与思考强度，并在会话的子代理弹层中查看每个子代理最后使用的模型。

## 安装

```sh
dsh plugin --profile web add @klarkxy/dsh-model-hub
```

把 `web` 换成你的 profile 名，安装后重启 profile。

## 使用

打开「设置 → 子代理」，添加、替换或移除模型，选择思考强度，并填写可选的任务倾向。这些内容供智能体委派时参考，最终选择仍由智能体决定。

在会话中点开子代理数量或切换器，可查看每个子代理最后使用的模型与思考强度。此处只读。

## 限制

- 名单修改对新建会话生效，已有会话沿用原名单。思考强度用于新建子代理，不修改正在运行的子代理。
- 选模需要宿主工具支持。省略模型时仍继承父代理模型。
- 模型与强度选项来自宿主目录。读取失败时点「重试」，其他可用提供方不受影响。
- 弹层依赖宿主私有的树与样式约定，宿主改动可能需要插件适配。外部子代理和未发起模型请求的子代理没有可显示的路由。
- 别处改动会自动同步；编辑冲突时刷新后重新选择。

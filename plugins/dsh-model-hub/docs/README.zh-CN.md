# 模型枢纽

<!-- release-state-note -->

[English](../README.md)

在一个页面查看并修改各个 DeepSeek Harness 插件使用的模型，也可以管理子代理可用的模型。

## 安装

```sh
dsh plugin --profile web add @klarkxy/dsh-model-hub
```

把 `web` 换成你的 profile 名，安装后重启 profile。

## 使用

打开「插件 → 模型枢纽」。

- **字段总览**：列出已安装插件提供的模型设置，例如自动标题、Git 提交、安全自动和 ChatGPT。可以按插件、用途或当前模型搜索，再选择新模型；改动由对应插件保存。
- **子代理阵容**：开关子代理模型白名单，添加、替换或移除模型。每个模型可以写一句「任务倾向」，主智能体选择子代理模型时会参考它，但不强制。

## 限制

- 只显示提供了模型设置的插件。
- 设置在别处被改动时，刷新后重新选择。
- 不提供用量统计。

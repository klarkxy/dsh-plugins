# 模型选择器

<!-- release-state-note -->

简体中文 / [English](README.en.md)

为 DeepSeek Harness 输入框替换模型按钮：用元素周期表式的卡片选模型和思考强度，也可以切回可搜索的列表。其他插件可以复用同一个选择器。

## 功能

### 卡片视图（默认）

每个模型一张卡片：左上角是序号，右上角是供应商，中间是大号简称、数字版本角标、完整后缀小字和完整模型名，底部是思考强度格。

- **筛选**：打开后直接打字即可筛选，按模型名、简称或供应商匹配（`gpt5` 也能找到 `gpt-5`）；回车选中第一个结果，Esc 先清空筛选再关闭。
- **选模型**：点卡片中间，只选模型，不指定思考强度。
- **选模型和强度**：点底部某个强度格，一次选好；再点一次已选中的格子取消强度。
- **切换供应商**：多个供应商提供同一模型时合并成一张卡片，点右上角切换；新供应商支持当前强度时保留不变。
- **简称**：常见模型直接显示易辨认的厂商名或模型名（如 `Kimi`、`Terra`、`DeepSeek`、`Opus`），数字版本显示为角标，`Flash`、`Pro`、`Lightning` 等后缀用完整小字显示，其余模型自动取完整的首个名称词。双击简称可改名，回车保存，Esc 放弃，清空恢复默认。
- **排版**：拖动卡片到另一张卡片的两侧插入，拖到中间互换位置；顶部滑块调节卡片宽度，「恢复默认布局」清除排序和自定义简称。
- **右键菜单**：右键卡片可以收藏（收藏的模型排在最前并带 ★）、移到最前或最后、修改或恢复简称、复制模型 ID、隐藏。隐藏的模型可通过顶部「已隐藏」按钮重新显示并取消隐藏。
- **动效**：面板、卡片和菜单带有淡入与位移动效，调整顺序时卡片平滑移动；系统开启「减少动态效果」时全部关闭。

### 列表视图

点顶部「列表」切换为按供应商分组、可搜索的列表，思考强度用滑杆调节。点「卡片」切回。

### 其他行为

- 选好的模型和思考强度会作为新会话的默认值。
- 列表视图中切回本次打开页面后用过的模型，会恢复它上次的思考强度。
- 模型列表加载失败时可重试；已保存但不在可用目录中的模型会标出，不能再选。
- 子代理会话不提供模型选择，与原生按钮一致。

## 安装

```sh
dsh plugin --profile web add @klarkxy/dsh-model-picker
```

把 `web` 换成你的 profile 名，重启 profile 后生效，无需配置。

与 `reasoning-slider` 同时安装时以本插件为准；禁用或卸载本插件后，恢复为 `reasoning-slider` 或原生按钮。

## 其他插件接入

功能插件可以在自己的设置页或卡片里挂载这个选择器。本插件未安装时，这些功能继续使用各自原有的菜单。接入方式见 `@klarkxy/dsh-model-route`。

## 主要限制

- 只替换输入框的模型按钮和共享选择器，「设置 → 模型」页面保持原样。
- 视图、卡片宽度、排序、收藏、隐藏、自定义简称和首选供应商只保存在当前浏览器，不跨设备同步。

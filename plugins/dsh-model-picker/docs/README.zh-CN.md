# 模型选择器

为 DeepSeek Harness 输入框提供带搜索的模型选择与推理档位滑杆——同一份选择器也以可复用组件形式提供给其他插件挂载。

<!-- release-state-note -->

## 功能

- 替换输入框的模型按钮：单层面板内按供应商分组搜索模型，下方提供加粗的渐变推理档位滑杆、更大的滑块和拖动反馈；动效遵循系统的「减少动态效果」设置。
- 成功选择的模型和思考强度会作为新会话默认。切回本次打开页面期间使用过的模型时，会恢复它支持的上次档位，否则使用模型默认；选择「默认」会清除显式档位。
- 选择模型或调整推理档位后面板保持打开，保留搜索内容和滚动位置。加载失败可重试；已保存但不可路由的模型会被标记且不能再次选中。
- 子代理会话不可用模型选择，与原生一致。

## 安装

无需配置；启用后即替换输入框的模型按钮。

与 `reasoning-slider` 同时安装时本插件生效；禁用或移除本插件后，按钮回退到之前的占用者——reasoning-slider 或原生按钮。

## 其他插件接入

功能插件可在自己的设置页或卡片里挂载同一选择器。接入是可选的：本插件缺席时各功能继续使用原有菜单，禁用或卸载不影响它们。接入契约见 `@klarkxy/dsh-model-route`。

## 限制

- 只覆盖输入框模型按钮与共享选择器；「设置 → 模型」页面保持原生布局。
- 已保存但离开目录的模型仍显示，但标记为不可路由且不能再次选中。

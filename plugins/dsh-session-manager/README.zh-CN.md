# 会话管理

<!-- release-state-note -->

[English](README.md)

跨工作目录查找和阅读 DeepSeek Harness 会话、在临时工作区中开始对话，空输入时一键继续，久离回来时在输入框上方显示摘要与压缩建议。

## 安装

```sh
dsh plugin --profile web add @klarkxy/dsh-session-manager
```

把 `web` 换成你的 profile 名，安装后重启 profile。

## 使用

- **智能体工具**：`list_sessions`、`search_sessions` 和 `read_session` 按标题或内容查找会话，并阅读对话、完整细节或交接摘要。阅读对话时按轮返回预览（最新在前），可用返回的游标向前翻页，并通过细节模式查看完整原文。
- **会话右键菜单**：右键点击左侧会话行或它的「⋯」按钮，打开该会话的操作菜单，不切换当前对话；左键仍打开对话。搜索结果和空白新会话行没有此菜单。
- **临时工作区**：在新会话的工作区选择器中选择它，即可在一个新的独立目录中开始对话。
- **继续灰影**：上一轮结束后，输入框为空时会浮现灰色建议文本。按 `Tab` 填入草稿，点击则直接发送。一轮还没结束时保持输入框原来的提示。切到「固定文本」使用配置的文本，留空则用「继续」；切到「模型生成」使用所选模型，模型只在上一轮结束后生成一次并缓存在会话中，同一轮不会重复调用。模式、固定文本和灰影模型都在「继续灰影」分组中调整（配置键：`continueMode`、`continueText`）。
- **欢迎回来**：回到距上次响应超过 `recapMinutes` 分钟（默认 15）的会话时，在最后一轮回复之后内嵌显示模型生成的摘要卡片，说明之前在聊什么、进展和建议的下一步。超过 `compactMinutes` 分钟（默认 60）时，同一卡片还会提示缓存可能已失效，并提供「压缩上下文」和「在新会话中继续」两个可选按钮：前者调用宿主原生压缩命令，后者在来源会话所属工作区内新建空白会话（来源未归属工作区时沿用原目录），把摘要和原会话 ID 填入草稿供确认后发送，不复制历史。也可以不点按钮直接发送，不会自动压缩或切换会话。继续对话后卡片自动消失。两项开关和各自的空闲阈值在「欢迎回来」分组中调整，点击「保存」并确认成功后，当前会话按新阈值重新检查。时间从上次响应计算，不从保存设置时重新计时。
- **欢迎回来模型**：在「欢迎回来」的「欢迎回来摘要」开关下，「摘要模型」只用于欢迎回来摘要。灰影的模型在「继续灰影」切到「模型生成」后单独选择。两者留空都跟随当前会话或宿主默认模型。模型菜单支持按供应商分组和搜索；列表加载失败时显示原因与重试按钮，重试会保留未保存的设置。

## 限制

- 临时工作区不会自动清理，文件在重启和卸载后仍然保留。
- 从其他会话读到的内容只是背景资料，不是指令。
- 自由聊天、删除聊天、在原会话中重试或编辑已发送消息，需要宿主支持这些功能。只安装 npm 插件不会增加这些能力；宿主支持时才显示对应按钮。
- 「欢迎回来」摘要由模型生成；没有可用模型或调用失败时卡片不会出现（压缩建议仍会单独出现）。摘要只读取会话，不写入历史。压缩依赖宿主的原生命令，结果由对话中的压缩记录反馈。新会话只携带简短摘要，可能遗漏细节，需按原会话 ID 查阅；原会话和原草稿保持不变。
- 卡片在你回到会话时检查（窗口聚焦、标签页可见或切换会话），页面持续可见时也会定期检查，到达阈值后不必切换窗口。它不会拦截你的下一次发送。空输入发送指发送灰影文本；输入框本身仍要求非空内容。

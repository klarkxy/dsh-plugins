# 快速评审

<!-- release-state-note -->

简体中文 / [English](README.en.md)

一键从当前对话派出一个只读评审会话：它在右侧面板里实时展开，只评审本会话产生的改动，首轮评审结论自动发回当前对话。

## 演示

![对话头部「评审」→ 弹窗选模型与关注点 → 右侧标签页实时评审](https://raw.githubusercontent.com/klarkxy/dsh-plugins/docs/demo-assets/pr29-quick-review.gif)

## 安装

```sh
dsh plugin --profile web add @klarkxy/dsh-quick-review
```

将 `web` 替换为你的 profile 名称，按 DSH 提示重启 profile。

## 使用

1. 打开一个已经产生过文件修改的对话。
2. 点击对话右上角的「评审」。
3. 在弹窗中选择评审模型（会记住上次选择；留空跟随宿主默认对话模型），可填写「关注点」，点击「开始评审」。
4. 右侧面板打开评审标签页，实时显示评审会话的完整对话；标签页顶部显示评审状态。
5. 评审首轮结束后，最终结论自动发回主会话。与评审会话继续对话后，可点标签页里的「再次发回主会话」把最新回答再发一次。

## 主要限制

- 评审范围取宿主的会话改动记录（`workspace/changes` 汇总）；宿主重启或会话没有改动记录时，回退为「工作区全部未提交改动」，弹窗和评审提示会如实说明。
- 评审会话固定使用宿主内置的 `read-only` 权限预设（只读沙箱 + 写操作需批准）；宿主缺少该预设时插件拒绝启动，不会放行可写评审。
- 评审模型只写入评审会话，不改动全局默认模型。
- 首轮评审只自动发回一次；评审被中止、失败或没有产出文本时不会发送，状态在标签页中显示为未成功。
- 空白会话与子代理会话不显示评审入口；「再次发回主会话」依赖插件运行中的内存记录，宿主重启后不可用。

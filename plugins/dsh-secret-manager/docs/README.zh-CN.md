# 密钥管理器

<!-- release-state-note -->

[English](../README.md)

在对话之外收集密钥。智能体需要 API Key 或令牌时，通过专用弹窗向你请求：输入值直接送到本机宿主，不写入对话，工具只拿到 `secret://<slot>` 引用。使用按会话授权 —— 分别限定本会话 shell 调用和精确的 HTTPS 来源。

## 安装

本包处于 draft 阶段，尚未发布到 npm。请从本仓库检出中以本地构建安装：

```sh
dsh plugin --profile web add ./plugins/dsh-secret-manager
```

把 `web` 换成你的 profile 名，重启 DSH Web。正式发布后同一命令可使用 scoped 包名 `@klarkxy/dsh-secret-manager`。

## 使用

### 回应智能体的请求

模型调用 `request_secret` 时，弹窗会在对话中自动打开：

- 在掩码输入框中输入密钥；留空则复用该 slot 已保存的值。
- 勾选**本会话**允许的使用方式：shell 使用（`DSH_SECRET_*` 环境变量）和/或向显示的精确 HTTPS 来源、以显示的认证头发送（默认 `Authorization: Bearer`，除非你批准了请求中指定的其他头/前缀）。
- 「拒绝请求」拒绝本次请求；关闭弹窗效果相同，请求不会无限等待。若拒绝未能到达宿主，界面会显示错误并可重试——不会谎称已取消。提交或关闭时输入框即被清空。

请求未决期间，对话中的工具行显示"等待你确认密钥"，带「打开授权」按钮可重新打开弹窗。工具结果只携带状态 —— 授权范围与 `secret://` 引用 —— 不含密钥值。

### 管理密钥

打开「设置 → 密钥管理器」：

- **密钥**：输入名称和值新增（同名覆盖），经确认弹窗替换值，或删除。值始终掩码、不回显、不保留尾号。
- **本会话授权**：对当前打开的会话，撤销其对某个密钥的授权，或撤销该密钥在全部会话的授权，均不删除值本身。

shell 使用与 HTTP 发送分开授权。授权限定当前会话且有时效，默认不对全部会话开放。

## 限制

- 录入值通过专用弹窗直接提交给宿主；保存和授权的工具结果只含引用与状态，不含密钥值。插件不把录入值写入浏览器持久存储或自身日志。
- 密钥在本机以明文保存——它是引用管理器，不是加密保险箱。能读到 DSH 数据目录的人就能读到这些值。
- 授权绑定当前会话：约一小时后过期，插件卸载或宿主重启即清除；替换或删除值会立即撤销该密钥的全部授权。不继承给子代理；未回答的请求几分钟后自动过期。
- shell 使用仅支持原生非持久 shell，持久 shell 不支持。
- HTTP 使用仅限精确来源：密钥按你批准的认证头发往显示的 `https://` 源——默认 `Authorization: Bearer`，除非请求指定并经你批准了其他头/前缀——不支持整域或通配符。
- 脱敏覆盖录入通道与正常工具结果，不覆盖流式输出、溢出文件、编码改写或外部日志；会话自己的 shell 也能读取被授权的 `DSH_SECRET_*` 变量，请谨慎授权。
- 没有全工具透明替换：已把明文密钥写进参数的工具不会被自动改写。
- 没有自动授权：智能体可以请求，但保存、授权、替换和撤销都由你显式确认。

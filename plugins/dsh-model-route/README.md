# @klarkxy/dsh-model-route

<!-- release-state-note -->

[简体中文](docs/README.zh-CN.md)

A small shared library that lets plugins describe their model settings in the same way, so Model Hub can find and edit them, and share model lists with loading, error, and retry feedback. It adds no feature of its own and does not need to be installed separately. For plugin developers, the source code and type declarations are the reference.

# @klarkxy/dsh-model-route

<!-- release-state-note -->

[简体中文](docs/README.zh-CN.md)

A small shared library that lets plugins describe their model settings in a unified format and share model lists with loading, error, and retry feedback. Plugins that depend on it install it automatically. For plugin developers, the source code and type declarations are the reference.

# @klarkxy/dsh-model-route

<!-- release-state-note -->

[简体中文](docs/README.zh-CN.md)

Shared library that lets DeepSeek Harness plugins define provider, model, and reasoning-effort settings in a unified format (Zod and Schemastery) and share model lists and picker menus with loading, error, and retry feedback. Plugins that depend on it install it automatically; plugin developers should refer to the source code and type declarations.

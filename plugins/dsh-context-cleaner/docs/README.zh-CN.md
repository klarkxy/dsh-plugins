# 上下文面板清理

<!-- release-state-note -->

本插件隐藏 dsh-context 仪表盘右上角的两张装饰卡片：插件信息卡和推广/推荐卡。隐藏后整列收回，统计卡铺满顶部一行。

## 安装

先安装并启用 `dsh-context`——本插件只做清理，不提供上下文面板本身。

在源码检出中，通过 DSH 插件管理器安装 `plugins/dsh-context-cleaner` 目录（也可使用其绝对路径），并启用「上下文面板清理」。无需其他配置。

## 使用

无需操作。插件启用期间，dsh-context 面板中的插件信息卡与推广卡保持隐藏——上下文标签页和侧边栏入口同样生效。停用或卸载本插件会移除规则，卡片随之恢复。

## 主要限制

- 隐藏依赖 dsh-context 渲染出的界面结构，上游改版可能需要本插件同步适配。
- 仅做视觉隐藏——dsh-context 后台仍会发起推荐内容请求。

# Git 提交

<!-- release-state-note -->

[English](../README.md)

在对话里直接提交工作区改动。模型会把改动分成几个合理的提交，并写好提交信息。

## 安装

```sh
dsh plugin --profile web add @klarkxy/dsh-git-commit
```

把 `web` 换成你的 profile 名，DSH 提示时重启。

## 使用

1. 打开一个工作目录位于 Git 仓库内的对话。
2. 点击对话右上角的「提交」。
3. 确认分支、文件数和模型后提交。
4. 面板会列出创建的提交。

在「提交」面板里可以选择**提交规划模型**——选择会保存为以后提交的默认值，也可以打开**模型不可用时仍然提交**，在模型不可用时合并为单次提交。安装可选的「模型选择器」插件后，该菜单会升级为带搜索和推理等级滑杆的共享选择器；未安装时保持现有控件不变。

规划模型留空时跟随「默认辅助模型」；没有设置默认辅助模型时，使用当前会话模型，再回落到宿主默认对话模型。默认辅助模型是共享设置：在「设置 → 会话管理」里设置一次，所有跟随它的功能都用同一个模型。

模型列表读取失败或部分提供商不可用时，可在模型选择器旁点击「重试」；已保存的模型选择会保留。

## 注意

- 仓库跟随对话当前的工作目录；规划提交期间切换目录会停止本次提交。
- 会提交仓库里全部未提交的改动，包括新文件。
- 提交规划沿用所选模型的正常输出设置，插件不额外限制输出长度。
- 仅在本地创建提交，推送由你自行决定。
- 中途停止时，已完成的提交会保留，面板显示剩余待处理内容。
- 每次规划都根据工作区当前改动重新组织输入，不会复用以前的规划结果；共享默认辅助模型读取失败时本次运行直接失败，而不是换一个你没选过的模型。
- 按钮在会话空闲时可用。

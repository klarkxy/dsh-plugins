# Git 提交

<!-- release-state-note -->

[English](../README.md)

不离开对话就能提交工作区改动。模型会把改动分成几个合理的提交，并写好提交信息。

## 安装

```sh
dsh plugin --profile web add @klarkxy/dsh-git-commit
```

把 `web` 换成你的 profile 名，DSH 提示时重启。

## 使用

1. 打开一个工作目录位于 Git 仓库内的对话。
2. 点击对话右上角的「提交」。
3. 确认分支、文件数和模型后提交。
4. 面板会列出创建的提交。

在「插件 → Git 提交」里可以选择**提交规划模型**（留空跟随当前会话模型），也可以打开**模型不可用时仍然提交**，这时所有改动合并为一个提交。

## 注意

- 会提交仓库里的全部未提交改动，包括新文件。
- 只提交，不推送。
- 中途停止时，已完成的提交会保留，面板显示剩余内容；不会自动回滚或重试。
- 会话运行期间按钮不可用。

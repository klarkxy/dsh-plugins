# Deep View 智能界面

<!-- release-state-note -->

简体中文 / [English](README.en.md)

在助手回复中组合原生图表、对比、流程步骤、指标、可调估算与可探索互动视图，并将操作转化为回答。普通 Markdown 正文可与互动界面自然穿插。

## 演示

![模型写出 HTML 并打开 Deep View 画布，预览报错后填入输入框并修复](https://raw.githubusercontent.com/klarkxy/dsh-plugins/docs/demo-assets/deep-view-canvas-live.gif)

## 安装

```sh
dsh plugin --profile web add @klarkxy/dsh-deep-view
```

把 `web` 换成你的 profile 名，安装或更新后重启 profile 并刷新页面。包内同时包含 Host 与 Web Client 两部分，无需账号或 API 密钥。

## 使用

直接提出架构原理、调用链、数据趋势、方案选型、可调预算、互动数学图、数据探索或地图等需求，无需点名 Deep View。插件会在面向用户的会话中同时提供系统提示词选用策略与运行时协议说明，让模型主动用节点关系图说明架构与调用链、用图表呈现数据趋势、用本地控件支持多档估算与追问确认；正文和代码仍可自然穿插。

同一 profile 启用插件后，所有预设的面向用户会话共用这套界面协议，包括普通聊天、计划模式、PTC 代码执行模式，以及使用自定义完整提示词或关闭可选上下文的模式。切换模式无需重新配置。工具不可用时仍可在回复正文中生成常用视图；计划模式的执行限制、用户指定格式和严格结构化输出要求仍然有效。

常用关系图、图表、对比表、步骤、可调估算（含 `slider`、`number`、`choice`、`toggle`）以及快捷选项与确认（`options`、`confirm`）无需先加载 skill。`deep-view` skill 保留为互动数学坐标系（`math`）、联动散点探索（`explore`）、地图（`map`）及多字段表单（`form`、`submit`）的参考。你也可以明确要求「用纯文本回答」「只输出 Markdown」或指定其他格式；简短事实与纯代码任务不会被强行套上卡片。委派子代理不会收到这套主动选用提示，汇总答案的主会话负责组织最终界面。

### 两种界面入口

- **正文界面（`deepui` 声明）**：模型在段落之间输出 `deepui` 声明块，流式生成期间待其 JSON 完整后即在原位置替换为原生卡片，让图表、表格、指标与估算留在阅读顺序中。卡片内的回答操作通过 **填入输入框** 写入草稿，由你确认后发送。
- **任务界面（`show_view` 工具）**：用于在回复正文出现前展示进度，或渲染需要由 Host 校验并直接提交的待答卡片。进度类视图通过输入框上方一个可替换的活动槽位实时刷新；待答卡片在回合运行期间可停靠在输入框上方，回复结束后保留在正文中，同一时间每个会话仅允许一个可编辑的待答卡片。
- **画布预览（`show_canvas` 工具）**：模型为原型、小游戏、可交互演示或完整页面写出 `.html` 文件后，可调用 `show_canvas` 在右侧 Sidebar 打开可运行预览；工具结果卡片上的 **打开预览** 按钮可随时重新打开。画布会成为 `.html` / `.htm` 文件的默认渲染器，原生 HTML 预览仍可在渲染器下拉中选择。

### 画布预览

- **需要开启「显示代码工作视图」**：画布只在宿主的「显示代码工作视图」开关开启时注册并运行脚本；关闭时该渲染器消失，文件回落为原生静态 HTML 预览。
- **错误条与填入输入框**：预览脚本抛错、未处理的 Promise 拒绝或 `console.error` 会汇总在预览下方的错误条中（相同报错合并计数）。点 **填入输入框** 会把错误列表写入草稿交给模型修复——已有草稿时先询问替换或追加，绝不自动发送；也可复制错误。
- **自动刷新**：模型随后用 `edit` 修改文件（包括相对引用的本地脚本与样式）会自动重载预览并清空错误条，无需重新调用工具。

### 组件、互动视图与公式

两种入口共用同一套组件与共享状态：

- **布局与基础组件**：布局支持 `stack`、`row`（最外层布局可定义 `let` 变量供公式读取）；展示支持 `text`、`metric`、`table`（单元格支持行内 Markdown 代码、加粗与链接）、`chart`（`bar`、`hbar`、`line`、`area`、`donut`，支持表格视图切换与复制数据）、`progress`、`callout`、`sources` 与 `steps`；本地输入支持 `slider`、`number`、`choice` 与 `toggle`。
- **公式计算**：写作 `{ "=": "price * count" }`，支持四则运算、幂运算（`**` 与 `^`）、比较、条件表达式、内置常量（`PI`、`E`）与固定数学/聚合函数集，不执行任意 JavaScript。
- **四类可探索视图**：
  - `math`（Mafs）：在声明的 `domain` 与 `range` 内绘制坐标系，支持 1–4 个可拖动坐标点与最多 4 条 `f(x)` 曲线。视图固定在声明范围内（不平移、不缩放），曲线与同卡片公式可实时读取各点坐标、本地控件与 `let` 变量。
  - `flow`（React Flow）：绘制声明的节点关系图，省略节点坐标时自动按拓扑分层排版并自适应四向连线，支持平移、缩放、拖动节点排布及选中节点查看详情，选中结果可供同卡片读取（不支持新增、删除或连接节点）。
  - `explore`（Vega-Lite）：将内联标量数据画成散点图并附带可折叠数据表，支持点击数据点按分类筛选或拖拽框选 `x`/`y` 区间（双击清除），选择结果联动回卡片。
  - `map`（MapLibre）：显示声明的地点与路线，并在地图旁始终渲染无障碍地点列表；选中的地点同步供给同卡片读取。
- **同卡片联动**：输入控件变更以及数学点坐标、节点、地点或散点选择会立即驱动同卡片公式、指标与表格重算，无需再次请求模型，并一并写入可读回答。

### 回答、更新与恢复

- **回答方式**：支持 `options`（单选/多选）、`confirm`、`form` 与 `submit`。`show_view` 的直接提交在写入会话前由 Host 按声明的控件与当前 `revision` 校验；正文 `deepui` 卡片（以及在 `show_view` 卡片中选择 **填入输入框**）会把回答格式化填入草稿（输入框已有草稿时会先询问替换或追加），从不静默发送。
- **原地更新**：`show_view` 可携带 `view_id` 与上一版 `revision` 在原位置替换卡片为新版本；过期的 `revision` 或针对已替换、已关闭卡片的回答会被拒绝，不会覆盖最新状态。
- **恢复与只读**：直接提交的回答以及可明确对应的输入框回答会在刷新或重新打开会话后随界面恢复；已回答过的卡片转为只读状态。

## 主要限制

- **选用与渲染时机**：提示策略会引导模型主动选用界面，但不保证每次生成卡片，也不会强制所有回复使用可视化布局或改变普通 Markdown 的渲染。`deepui` 围栏需等完整 JSON 就绪后才渲染；常见的字段别名、字符串数字、缺省输入 ID 和多余展示字段会自动规范化，仍无法安全识别的声明会显示校验原因并保留原始代码供查看。
- **封闭原生控件**：不支持任意 JavaScript、HTML 或 `html` 组件，也不支持导出 PNG。`explore` 仅接受内联标量行数据（不支持完整 Vega-Lite spec 或远程数据源）；`map` 仅接受坐标与路线（不支持自定义样式 URL、瓦片服务或 API Key）；`flow` 仅渲染声明的节点和连线（不支持自定义节点组件）。
- **工具调用边界更新**：`show_view` 的活动更新以工具调用为边界，不会从其他长耗时工具内部流式推送进度，也不会改写历史工具结果。
- **会话与生命周期边界**：仅真人顶层会话或普通会话分叉中有效的 `show_view` 可直接通过 Host 提交回答（委派子代理不能收集直接回答）。插件重启会清除内存中未决的待答状态，但已保存内容仍可在会话中查看。
- **卡片有效期与隐私**：待答卡片在提交回答或收到新的普通用户消息后关闭，已回答卡片变为只读，未提交的本地调节不会自动持久化。请勿使用界面收集密码、密钥或 token。
- **画布预览边界**：卡片入口依旧不支持任意 JavaScript 与 HTML。画布依赖宿主文件预览管线：仅打包直接相对引用的经典 `<script src>` 与 `<link rel="stylesheet">`，不支持本地 ES module 导入、CSS `url()`/`@import` 引用本地文件或 `fetch` 本地文件；声明 `<base href>` 的页面不会打包本地依赖，请避免该元素。预览在隔离沙箱中运行脚本。关闭「显示代码工作视图」时回落为原生静态预览；`show_canvas` 仅面向用户的顶层会话可用。
- **地图环境依赖**：地图加载固定的公开远程示例底图，不接受其他样式源；离线、无 WebGL 或底图加载失败时，卡片会显示提示，下方的地点列表仍可正常选择。
- **体积与数量上限**：卡片载荷大小、组件数量与层级、曲线数、节点与连线数、数据行数及地点数均受上限限制，超限会被直接拒绝而不会静默截断。
- **外观随宿主适配**：主题配色与实际渲染取决于当前安装的 DSH Web Client。

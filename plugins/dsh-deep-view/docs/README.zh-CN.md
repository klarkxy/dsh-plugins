# Deep View 回复卡片

<!-- release-state-note -->

Deep View 在助手回复过程中展示交互式声明卡片：流程步骤、指标、表格、图表、进度、提示和来源。本地输入变化会立即联动公式，无需再次请求模型。

## 安装

通过 DSH 插件管理器安装 `@klarkxy/dsh-deep-view` bundle，然后启用 **Deep View 回复卡片**。包内同时包含 Host 与 Web Client，无需账号或外部服务。

## 用法

直接要求模型使用 Deep View 即可。遇到流程、数值对比、可调参数估算、进度或可选回答时，模型也可以主动使用。模型先加载按需提供的 `deep-view` skill，再调用 `show_view`；完整用法只在需要时加载。参数完整后，卡片可以在本轮尚未结束时立即显示，不再只等最终答复。

布局组件为 `stack`、`row`。展示组件为 `text`、`metric`、`table`、`chart`（`bar`、`hbar`、`line`、`area`、`donut`）、`progress`、`callout`、`sources`、`steps`。`steps` 用 `done`、`active`、`pending`、`blocked` 表达流程状态，不再用多层 callout 模拟流程图。`slider`、`number`、`choice`、`toggle` 是本地输入。公式写作 `{ "=": "price * count" }`，支持算术、比较、条件表达式和固定函数集，不执行 JavaScript。

`options`、`confirm`、`form`、`submit` 用于回答。待答卡可以显示在输入框上方；支持时提供两种动作：**填入输入框**把校验后的答案写入草稿，由你检查后发送；直接提交则向正在运行的顶层会话发送一份经 Host 校验的回答。已有草稿不会被静默替换。表单支持初始值、多行文本、只读字段和取消。

选择和填写结果会显示为可读消息，并随消息保存。刷新或重新打开会话后，卡片会恢复已提交的数值和选中项。当前进度使用一个可替换的活动视图，不连续堆积进度卡。图表支持键盘查看、表格切换和复制 CSV。

## 限制

- 卡片按需使用；不会强制所有回复采用卡片，也不修改保存的助手文本。正文中的 `deepui` 代码块保持普通代码。长文解释和代码可以继续使用 Markdown。
- 活动更新以工具调用为边界；不会从其他长时间运行的工具内部连续推送进度，也不会改写历史工具结果。
- 只有当前有效的 `show_view` 卡片能通过 Host 提交。插件重启后待回答记录会丢失，但保存的卡片仍可在会话中查看。
- 回答后或收到另一条普通用户消息后，待回答卡片会关闭。不要用卡片收集密码、密钥或 token。
- 旧版回答仅在保存的消息能够明确对应卡片及其数值时恢复；尚未提交的本地修改不会自动持久化。
- 不包含 `html` 组件和 PNG 导出，不执行模型编写的 HTML 或 JavaScript。
- 主题与实际渲染取决于安装的 DSH Web Client；源码构建成功不等于已完成运行时或视觉兼容验收。

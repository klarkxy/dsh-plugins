# Deep View 回复卡片

<!-- release-state-note -->

Deep View 在助手最终回复下方展示按需使用的声明式卡片：指标、表格、图表、进度、提示和来源，也支持本地输入；输入变化会立即联动公式，无需再次请求模型。

## 安装

通过 DSH 插件管理器安装 `@klarkxy/dsh-deep-view` bundle，然后启用 **Deep View 回复卡片**。包内同时包含 Host 与 Web Client，无需账号或外部服务。

## 用法

遇到数值对比、依赖可调参数的估算，或回复末尾需要你做选择时，模型会主动附上卡片；也可以直接要求模型生成。模型调用 `show_view` 工具并传入 `{ "title"?: string, "view": ViewNode }`；工具先准备卡片，模型随后继续输出最终答复。卡片直接显示在最终答复下方，不会被收进“已调用工具”的折叠区域。

布局组件为 `stack`、`row`。展示组件为 `text`、`metric`、`table`、`chart`（`bar`、`hbar`、`line`、`area`、`donut`）、`progress`、`callout`、`sources`。`slider`、`number`、`choice`、`toggle` 是本地输入。公式写作 `{ "=": "price * count" }`，支持算术、比较、条件表达式和固定函数集，不执行 JavaScript。

最终回复完成后，`options`、`confirm`、`form`、`submit` 可向正在运行的顶层会话提交一份经 Host 校验的回答。选择和填写结果会显示为可读消息，并随消息保存。刷新或重新打开会话后，卡片会恢复已提交的数值和选中项。图表支持键盘查看、表格切换和复制 CSV。

## 限制

- 卡片按需使用；不会强制所有回复采用卡片，也不修改保存的助手文本。正文中的 `deepui` 代码块保持普通代码，不渲染卡片；`show_view` 准备的卡片会在最终回复区域展示。
- 只有当前有效的 `show_view` 卡片能通过 Host 提交。插件重启后待回答记录会丢失，但保存的卡片仍可在最终回复区域查看。
- 回答后或收到另一条普通用户消息后，待回答卡片会关闭。不要用卡片收集密码、密钥或 token。
- 旧版回答仅在保存的消息能够明确对应卡片及其数值时恢复；尚未提交的本地修改不会保存。
- 不包含 `html` 组件和 PNG 导出，不执行模型编写的 HTML 或 JavaScript。
- 主题与实际渲染取决于安装的 DSH Web Client；源码构建成功不等于已完成运行时或视觉兼容验收。

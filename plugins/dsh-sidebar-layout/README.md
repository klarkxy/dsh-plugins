# 侧栏布局

<!-- release-state-note -->

简体中文 / [English](README.en.md)

让 DeepSeek Harness 的右侧边栏在三种呈现方式之间切换：

- **常规**：宿主默认行为，展开面板时挤压对话区域。
- **抽屉**：面板悬浮覆盖在对话之上，对话保持完整宽度；面板打开时对话区域出现一层遮罩，点击遮罩即可收起面板。
- **正文**：面板移入中间列作为正文，对话移到右侧（IDE 式布局），原有的右侧拖拽手柄此时调整的是对话列的宽度。

## 安装

```sh
dsh plugin --profile web add @klarkxy/dsh-sidebar-layout
```

把 `web` 换成你的 profile 名，DSH 提示时重启 profile。安装后默认启用，可在插件列表中关闭。

## 使用

布局是全局设置，三处入口改的是同一份状态：

- **会话头部按钮**：会话头部右侧工具条上的「侧栏布局」图标按钮，点击弹出菜单选择常规 / 抽屉 / 正文，当前方式有勾选标记。选择抽屉或正文时若面板处于收起状态会自动展开。
- **设置项**：「设置 → 通用」中的「侧栏布局」一行，下拉选择同一种方式。
- **快捷键**：`Ctrl/Cmd + Alt + Shift + B` 按「常规 → 抽屉 → 正文 → 常规」循环切换（网页版 Linux 不预置该快捷键，可在快捷键设置中自行绑定）。

选择会被保存在当前浏览器中，重新打开时恢复。

## 主要限制

- 面板的全屏模式不受本插件影响，三种布局下都保持宿主原样。
- 宿主在空间不足以容纳正常宽度的面板轨道时仍会自动收起面板，抽屉模式下同样如此。
- 本插件与 `dsh-better-sidebar` 可以同时使用，互不影响。
- 停用或卸载本插件后，侧栏恢复宿主默认的「常规」行为。

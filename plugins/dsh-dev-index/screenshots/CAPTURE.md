# dsh-dev-index interface captures

Captured on 2026-10-10 from the exact published `@klarkxy/dsh-dev-index@0.1.7` npm archive after checking its SHA-512 integrity.

The demonstration used an isolated, credential-free DSH home and an existing local source build of DSH 0.2.0-rc.2 with thread-management patches. This establishes that the shown plugin loaded and rendered in that demonstration host; it is not an upstream-host certification or a test across the entire declared compatibility range.

- `docs-development-zh.png`: official plugin-development documentation inside the Plugins page.
- `docs-zh.png`: Chinese official documentation.
- `docs-en.png`: the English language switch and official English documentation.
- `docs-walkthrough.mp4`: silent walkthrough assembled from these captured views, not a recording of a model run.

No model credentials were configured and no model request was made. The official documentation website reflects its current published content, which may differ from an older installed DSH release.

The media and `screenshots.json` are marketplace presentation assets and are outside the plugin's npm `files` list. The plugin license remains SATA 2.1.

# 快捷键

<!-- release-state-note -->

[English](../README.md)

修改 DeepSeek Harness 应用与已识别的局部快捷键，并通过命令面板执行已接入插件的命令。

## 安装

本包尚未发布到 npm。本地体验时，请使用包含客户端产物的完整本地构建，通过 DSH 官方插件管理器安装该产物。正式发布后，可通过同一管理器安装发布包。

在图形界面的配置档中启用插件，再按管理器提示刷新页面或重启配置档。

## 使用

打开 **插件 → 快捷键**：

- 查看当前原生命令快捷键与固定局部操作。命令加入或移除时，列表会实时更新。
- 修改、解绑或恢复应用快捷键及已识别的局部操作：发送、换行、互补发送、`/`、`@`、审批允许与拒绝、菜单移动／选择／关闭，以及双击停止。
- 在「其他快捷键」中，每个绑定都有改键、解绑和恢复按钮，同时显示原始键与生效键。菜单上下移动、互补发送的 Control／Meta 绑定可以分别修改。
- 停止操作保留双击确认。请选择不带修饰键的单键，例如 F8，并连续按两次；组合修饰键和同时双键无法保留宿主的停止序列。
- 打开命令面板，查找并执行已接入插件注册的命令。本插件注册的命令也会出现在原生快捷键列表中。

在 **Web 界面**中，额外的面板快捷入口默认为 **Ctrl+Shift+P**，与 VS Code 一致。可在插件设置中修改这个本地开键，包括手动选择 **Ctrl+K**。只有浏览器把按键传给页面时，它才能生效。

在**桌面端**，面板同样默认使用 **Ctrl+Shift+P**，可在插件设置中改键。**Ctrl+K** 已用于会话搜索（`session.search`）；若要用它打开面板，请在插件设置中查看并明确确认改键。这会替换会话搜索的 Ctrl+K 绑定。

原生快捷键改动由 DSH 保存：Web 保存在当前浏览器本地，桌面端保存在当前计算机。额外的 Web 面板开键和局部操作覆盖由本插件保存在本地，局部覆盖按 Web／桌面端和操作系统分别保存。

## 限制

- 命令面板只能执行本插件或其他已接入插件向它注册的命令。原生命令仍会显示在快捷键列表中，但出现在列表里不代表能从面板执行。
- 可用命令取决于当前界面与已加载的插件。固定操作可能只在所属界面打开时出现。未向 DSH 注册的第三方按键监听、终端或编辑器内部操作，以及浏览器和系统快捷键无法自动收集。
- 应用快捷键遵循宿主改键规则。局部覆盖只在识别到的输入框、审批、菜单或会话区域生效，并拒绝已知的全局按键冲突；不会删除宿主原始保留键声明。
- 局部覆盖适配当前宿主的已有控件。宿主升级改变操作签名，或第三方固定操作没有已识别适配时，界面会报告不兼容，不会假报改键成功。恢复操作默认键或停用插件可恢复原生行为。
- 浏览器或操作系统可能提前接管 Ctrl+K 或其他开键，导致页面收不到按键。遇到这种情况，可在设置中选择其他按键。
- Web 与桌面端的偏好分别保存在各自环境中；本插件不在浏览器或计算机之间同步这些设置。

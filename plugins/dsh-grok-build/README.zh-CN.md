# Grok Build · DSH 插件

<!-- release-state-note -->

通过本机官方 Grok Build CLI 搜索网页、抓取页面、生成及编辑图片、制作参考图视频。插件复用现有登录，不读取或复制登录令牌。

当前适配器仅接受已验证的 Grok Build 1.0.50；更新 CLI 后须先验证原生协议。

## 安装

```sh
dsh plugin --profile web add @klarkxy/dsh-grok-build
```

同时安装并登录官方 Grok Build CLI。进入「插件 → Grok Build」，若 CLI 不在 PATH 中，可填写可执行文件路径。状态检查只确认 CLI 与能力兼容，不证明模型调用已经登录成功；登录失败时请在 Grok 本身完成登录。

每次调用使用新的进程和临时配置，只把现有认证文件路径交给 Grok 自己读取。本次调用排除用户模型覆盖、项目说明、外部技能、插件及 MCP 工具，使用 CLI 内置默认模型。

## 能力

| 能力 | 用途 |
| --- | --- |
| 网页搜索 | 搜索公开资料并返回原生引用 |
| 页面抓取 | 使用 Grok 原生工具读取指定页面 |
| 图片生成 | 根据提示词生成图片 |
| 图片编辑 | 修改指定工作区图片或当前会话附件 |
| 图生视频 | 让指定图片动起来 |
| 参考视频生成 | 使用图片、预设音色或关键帧生成视频 |

本批不提供图片理解、X 搜索、独立音频生成和音乐生成。参考视频工具必须有参考素材，不是纯文生视频接口。

## 媒体文件访问

图片编辑和参考图视频需启用「允许 Grok 原生工具读取媒体文件」。插件校验指定文件，并为每次调用增加输入检查。这是额外检查，不是文件系统沙箱：官方 CLI 在检查钩子执行故障时会放行，因此这些能力沿用本机 Grok CLI 的文件访问权限。此项默认关闭。

输入须明确指定为当前工作区文件，或当前 DSH 会话中已有的附件。输出保存到工作区，并作为 DSH 原生图片或文件附件返回。只读工作区不能生成媒体。

取消会停止本次本地进程树，但不代表远端生成已经取消。Grok 原生视频工具在完成前不暴露远端任务编号；中断后保留不确定状态，不自动重复生成。恢复操作只取回已记录的本地结果。

已测版本、真实输出与验证边界见[验收记录](ACCEPTANCE.md)。

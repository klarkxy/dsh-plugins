# 安全自动

<!-- release-state-note -->

[English](README.md)

新增一个「安全自动」权限档位。普通操作照常在工作区沙箱里运行，插件不干预；需要审批的请求交给审核模型判断，通过就只放行这一次，不通过就把原因告诉智能体。做法参考 Codex 的自动审核（auto-review）。插件不会把会话切换成完全权限。

## 安装

```sh
dsh plugin --profile web add @klarkxy/dsh-safe-auto
```

把 `web` 换成你的 profile 名，安装后重启 profile。

## 使用

在输入框旁的权限菜单中选择「安全自动」。它只对当前会话生效，选回其他档位即关闭；选择之前不会有任何自动行为。

在「插件 → 安全自动」中选择审核模型（留空跟随当前会话模型）、思考强度和额外的审核要求。设置在别处改动时这个页面会自行更新，不需要安装模型枢纽。

模型列表加载失败或部分提供商不可用时，可在设置面板点击「重试」。重试会保留审核配置和未保存的草稿。

## 会审核什么

- `write`、`edit`、`bash`、`pwsh` 申请的沙箱提权。
- 少量危险命令，即使没有申请提权也会先审核：强制删除（`rm -f`、`Remove-Item -Force`、`del /f`、`rd /s /q`）和打开网址。
- 其他插件或工具在这个会话里发起的审批请求。

读文件、搜索、构建、测试这类不需要审批的操作不会被拦截，也不会调用审核模型。

## 审核怎么判断

- 审核模型会看到对话记录、当前工作目录、沙箱工作区边界和这次操作的完整参数。只有你发的消息算授权，智能体的说明、工具输出和文件内容都只作参考。
- 低风险和中风险的操作放行；高风险只在你明确要求且范围有限时放行；严重风险（例如把密钥发到外部、大范围不可逆删除）一律拒绝。
- 审核超时、返回字段缺失或含未知值、出错或模型不可用时，这次请求不放行，智能体会被告知这是审核失败，可以重试一次或者来问你。
- 同一轮对话里连续拒绝 3 次，或最近 50 次里拒绝了 10 次，就暂停自动审批，等你发下一条消息。

## 限制

- **这不是安全边界。** 审核方是语言模型，可能判断错误。请保留原有的沙箱、隔离和备份。
- 被拒绝的操作不会弹窗让你确认。想放行时直接在对话里告诉智能体，它重试时审核会看到你的批准。
- 对话记录超长时会截断最早的内容。
- 操作参数不会截断后送审；完整操作超出审核容量时不会自动批准。
- 关闭安全自动或修改审核设置，会使尚未完成的审核失效。
- 子代理会话不使用安全自动，按原生审批流程处理。
- 不要与其他自动审批插件同时使用。

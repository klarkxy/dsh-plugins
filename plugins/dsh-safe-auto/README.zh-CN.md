# 安全自动

<!-- release-state-note -->

[English](README.md)

新增一个「安全自动」权限档位。智能体请求在沙箱之外执行命令或修改文件时，由独立审核模型检查这一次调用。通过就继续；不通过时给你 60 秒决定批准还是拒绝。插件不会把会话切换成 Full Access。

## 安装

```sh
dsh plugin --profile web add @klarkxy/dsh-safe-auto
```

把 `web` 换成你的 profile 名，安装后重启 profile。

## 使用

在输入框旁的权限菜单中选择「安全自动」。它只对当前会话生效，选回其他档位即关闭；选择之前不会有任何自动行为。

请求未通过审核时，会弹出确认窗口，显示完整操作、审核意见和倒计时。你可以仅批准这一次，或者拒绝；无人响应即拒绝。

在「插件 → 安全自动」中可以选择审核模型（留空跟随当前会话模型）、思考强度，以及额外的审核要求。

## 覆盖范围

- `write`、`edit`、`bash`、`pwsh` 的沙箱提权，每次只放行一次调用。
- 少量明显无害的命令（如 `ls`、`pwd`）无需调用模型直接放行。
- 凭据文件、私钥和危险程序始终拒绝。
- 其他工具、MCP、远程执行和子代理不会自动放行。

## 限制

- **这不是安全边界。** 审核方是语言模型，可能判断错误。请保留原有的沙箱、隔离和备份。
- 批准与执行之间，文件仍可能发生变化。
- 不要与其他自动审批插件同时使用。

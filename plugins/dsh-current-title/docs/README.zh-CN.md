# 自动标题

<!-- release-state-note -->

[English](../README.md)

让 DeepSeek Harness 的会话标题跟着你手头的任务走；你手动改过的名字保持原样。

```text
0903 | 修复 | 登录回调失败
```

## 安装

```sh
dsh plugin --profile web add @klarkxy/dsh-current-title
```

把 `web` 换成你的 profile 名，DSH 提示时重启。安装后默认启用，可在插件列表中关闭。

## 使用

标题会自动更新。展开「设置 → 会话管理 → 自动标题」可以：

- 选择标题跟随每条消息，还是只看第一条消息；
- 填写自己的标题提示词；
- 选择标题模型（留空跟随默认辅助模型）；
- 重新生成当前会话的标题。

安装可选的「模型选择器」插件后，这些模型菜单会升级为带搜索和推理等级滑杆的共享选择器；未安装时保持现有控件不变。

标题模型留空时跟随「默认辅助模型」；没有设置默认辅助模型时，使用当前会话模型，再回落到宿主默认对话模型。默认辅助模型是共享设置：在「设置 → 会话管理」里设置一次，所有跟随它的功能都用同一个模型。

模型列表读取失败或部分提供商不可用时，可在模型选择器旁点击「重试」；重试会保留已保存的模型和提示词草稿。

## 限制

- 每次生成标题调用一次模型，使用模型支持的最低思考强度；生成失败时保留原标题。
- 每次调用都根据会话当前消息重新组织输入，不会把以前的标题回答带回后续生成；共享默认辅助模型读取失败时生成直接失败，而不是换一个你没选过的模型。
- 取消和超时会等待模型调用停止；忽略取消请求的提供商可能延后完成时间。
- 关闭插件后，标题交还给 DSH 自带的标题功能。

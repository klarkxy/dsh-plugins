# 委派模式

<!-- release-state-note -->

[English](../README.md)

按会话开启的委派开关：主代理负责拆解、委派和验收，具体工作交给子代理。开启后，主代理作为协调者把请求拆成任务、交给子代理执行并验收结果；子代理会话会同步获得对应的执行指引。

## 安装

```bash
dsh plugin --profile web add @klarkxy/dsh-delegation
```

在 profile 中启用插件，然后按插件管理器要求刷新页面或重启 profile。

## 使用

- 在创建会话页，发送第一条消息前，使用工作区、预设选择器同一行的「委派」按钮：未开启时为普通样式，开启后显示主题色。选择在会话开始后锁定，重新打开也保持不变。从已有会话分叉出的会话继承父会话的状态。按钮作用于该会话的主代理，它的子代理会自动获得对应的执行指引。
- 简单任务可以直接完成；较大任务由主代理先分派具体工作，再协调共同接口、检查子代理结果，最后汇报完成情况。

## 限制

- 带子代理工具的预设（Standard 与 PTC）可使用委派；无子代理工具的预设（如 Minimal 及其他完整人设预设）按钮显示为禁用状态。
- 按钮仅调整提示词引导，保持原有的工具与权限设置，通过提示引导模型委派。
- 委派模式在会话开始后保持固定，以维持提示词缓存稳定。
- 已有会话保持原状态；之前保存过的全局默认值仍作用于之后新建的会话。
- 新增的提示词小节可能降低模型供应商的提示词缓存命中率。

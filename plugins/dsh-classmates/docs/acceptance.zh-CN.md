# Classmates 本地交付验收

日期：2026-09-25。交付版本：`0.1.0-alpha.1`。结论：**本地实现和验收完成，可在已测 DSH Web 组合安装使用。** 未执行 npm 发布、远程部署或 Release。

## 已实现

设置页支持角色增改删、启停、模型与思考强度选择、工作指令、保存冲突比较以及演示请求复制。默认三个角色停用且未绑定模型。主控通过两个发现/创建工具按需调用；成员、消息、任务板和会话生命周期全部使用官方 Agent Teams。

成员创建时冻结配置，第一次请求前安装其模型选择和指令。模板之后的编辑、停用和删除不重写旧成员。绑定文件使用宿主的原子写入和文件锁；缺失、损坏或无法使用的模型绑定会报错，不静默退回主控模型。

本机模型测试通过一个 OCG provider 连接用户指定的三个模型。没有把网关后面的供应商数量算作跨供应商直连验证；参数接受也不等于测量了模型内部推理量。

真实模型首次创建时曾遗漏 revision、使用非法名称。插件拒绝了错误调用，模型修正后完成；没有额外创建失败成员。验收脚本曾因等待模型未采用的成员名而超时，实际会话已经完成；已修正脚本，并从持久化会话独立核对成功工具结果和完成事件。浏览器启动时还需处理宿主的一次设置窗口重建。这些过程保留在兼容说明中。

## 使用边界

只验证 DSH Web `0.1.7-rc.2`、Windows、Node.js `24.16.0`。先启用官方 Agent Teams，再安装本包。宿主升级应重新验收，尤其是原生设置容器的窄屏适配。

卸载前结束相关成员。热卸载运行中的 Classmates 成员不保证其绑定继续生效；旧成员恢复依赖插件和原 profile 的绑定文件。普通主会话不受影响。角色工作指令不构成权限沙箱。

rc.2 原生 roster 的模型标签可能显示主控模型，验收依据为实际请求元数据。MiniMax 的返回含 think 标签，本次确认完成和路由，未声称它严格遵循了短答格式。

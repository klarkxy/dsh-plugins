# 预设与聊天配置继承验收

日期：2026-09-25。当前本地开发候选，沿用未发布版本 0.2.0-alpha.1；没有发布或修改用户的正式 profile。

## 行为

- 11 个职责预设默认停用，模型和思考强度均跟随当前聊天。旧角色库不会自动合并或覆盖；设置页和配置助手均可采用预设。
- 模型与思考强度可独立继承或覆盖。角色顶层 `reasoningEffort` 支持只覆盖强度，旧的 `model.reasoningEffort` 继续可读；两者互相冲突时拒绝保存。
- 创建成员前，以主控自身最近一次请求的实际路由解析继承值；首次请求前使用 Agent 配置。模型与强度不兼容时明确报错，且不创建成员。
- 已保存的成员快照仍使用原有的具体模型格式。重试、进程恢复、角色删除和主聊天切换均不重新解释旧快照。
- 绑定已保存、但在原生创建前取消的重试，会校验请求身份后复用原绑定，防止聊天切换造成冲突。

## 本轮证据

- `npm run check`：类型检查、11 个测试文件中的 80 项测试及构建均通过。
- 新增运行时检查：两项继承、仅覆盖模型、仅覆盖强度、两项同时覆盖、实际请求路由捕获、主聊天切换后的继承、不兼容强度提前拒绝、取消重试和持久化冷恢复。
- `node scripts/preset-acceptance.mjs`：隔离 DSH Web profile 与本地模拟模型，通过真实 Edge 浏览器验证 11 项预设、ID 冲突时创建副本、保留已有角色、启用继承角色、强度单独覆盖及刷新回读、模型切换时保留强度、390px 窄屏。结果及截图位于 `.test-output/presets`。
- 独立审查发现并在修复后复验了“准备完成后取消重试”的问题。

## 提示词与界面文案修订

11 个内置角色的工作指令、共享约束，以及配置助手的 persona 和策略提示词已统一为英文；界面职责说明保持中文，回复语言仍跟随用户。未覆盖已保存的角色。

界面移除了重复的配置助手标题、保存后的长说明、字段模板解释，以及反复解释继承机制的段落；保留了表单标签、具体错误、冲突恢复、权限边界和成员生命周期提示。80 项检查与构建通过；浏览器复核包含英文指令回填、保存回读、390px 布局和辅助说明引用的完整性。

本轮远程模型调用为 0；不把本地请求捕获视为真实供应商验证。旧的真实供应商记录保留在历史验收文档中。

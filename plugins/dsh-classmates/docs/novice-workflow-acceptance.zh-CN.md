# 新手工作流修复验收

2026-09-25，DSH Web 0.1.7-rc.2、Windows、Node.js 24。

本轮由 Cursor 施工、测试，主控独立检查源码、复跑测试并操作真实宿主。验收以系统和插件正常工作为准，不要求模型严格遵循回复措辞、格式或角色数量。

## 修改

- 角色目录补充供应商公开名称；配置助手可读取自身当前请求路由，减少误选供应商。
- 设置页和配置会话增加“开始任务”，新建标准会话并放入可编辑的队友摘要。不会自动发送，也不覆盖旧会话草稿。
- 会话切换等待目标实际就绪，失败和超时可见；导航已提交后不假装能够取消。
- 成员模型信息随请求路由和运行状态刷新。显示使用成员自身请求记录，避免把 fork 继承的父会话模型当作成员实际使用。
- 增加独立临时工作区预检，检查实际受限写入及本轮浏览器点击；不读取旧演示的浏览器端点。

没有引入持久团队停止层、额外消息系统或模型回复拦截。停止与协作仍使用官方能力。

## 证据

- 类型检查、插件测试和构建由主控复跑；最终结果见工作区 `.test-output/novice-fix-acceptance/final-verification.json`。
- 真实官方宿主验证：管理 preset 挂载、角色原子批量修改、版本冲突拒绝、普通会话和成员不能使用管理工具、preset 切换后移除管理权限。
- 独立进程重启后可读取原团队角色与模型；只读查询没有激活 Agent 或请求模型。
- Edge 实际操作：成员信息、原生导航、任务负责人、键盘 Escape、390px 窄屏、深色主题、配置助手对话、标准会话交接及草稿发送。相关截图和结果在同一工作区验收目录。
- 本机 OCG 的短句配置试用发出 4 次 Step 5 Preview 请求，成功保存 4 个启用角色，绑定 Step 5 Preview、MiMo v2.6 Flash、space-bunny 三种 OCG 模型。它验证配置流程，不是团队重新制作完整游戏的验收，也不以模型措辞作为通过条件。
- 主控在普通宿主进程复跑环境预检，通过 AclSandbox 受限写入与实际 Edge 点击。嵌套在当前 Codex 命令沙箱内时，ACL 初始化仍会被 Win32 5 拒绝；脚本能明确报出该阻碍，没有修改全局安全配置。

## 本地候选包

修复候选沿用 `0.2.0-alpha.1`，保存在 `.test-output/novice-fix-acceptance`，与根目录原安装包分开。未公开发布。包内只包含插件构建和文档，不包含测试 profile、凭据、会话、录屏或临时工作区。

更换宿主版本、跨平台运行和持续长时间运行不在本轮验证范围内。配置助手指令用于引导模型，不构成权限沙箱或回复保证。

# @klarkxy/dsh-plugin-kit

<!-- release-state-note -->

[简体中文](docs/README.zh-CN.md)

Shared runtime and UI support library for the DeepSeek Harness plugins in this repository — covering the default auxiliary model, shared session settings, diagnostic logging, storage and host-client helpers, official UI styling, the optional shared model picker hookup, and subagent session detection. Plugins that depend on it install it automatically; plugin developers should refer to the source code and type declarations.

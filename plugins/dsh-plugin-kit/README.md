# @klarkxy/dsh-plugin-kit

<!-- release-state-note -->

[简体中文](docs/README.zh-CN.md)

A shared library used by the plugins in this repository. It adds no feature of its own and does not need to be installed separately; plugins that need it install it automatically.

For plugin developers, the source code and type declarations are the reference.

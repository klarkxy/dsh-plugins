# @klarkxy/dsh-plugin-kit

<!-- release-state-note -->

[简体中文](README.md) / English

Shared runtime and UI support library for the DeepSeek Harness plugins in this repository, providing the default auxiliary model, shared Session Management settings, diagnostic logging, storage and host-RPC helpers, official UI styling, optional shared model picker integration, and subagent session detection. Dependent plugins install it automatically; plugin developers should inspect the source code and type declarations directly.

# 桃乐丝（dot）

<!-- release-state-note -->

[English](../README.md)

DeepSeek Harness 的常驻调度管家桃乐丝，简称 dot。在她自己的面板里和她对话，她替你开工作区、派任务、跟进度，替你处理各会话的审批和提问，再向你汇报。你只需要在一个对话里交代事情，不用盯着每个会话。

她聊天轻松真诚，偶尔带一句欧润吉的口癖；干活时会把任务看住，把结果讲清楚。她的人设和对你的称呼都可以在设置里改。

## 安装

```sh
dsh plugin --profile web add @klarkxy/dsh-dot
dsh plugin --profile web add @klarkxy/dsh-deep-view
```

把 `web` 换成你的 profile 名，DSH 提示时重启。Deep View 负责在桃乐丝的对话里画选项、确认和图表卡片；没装时她改用文字提问。

## 使用

点侧栏「插件」「自动化任务」那一列里的 **桃乐丝**，面板打开时她的鲸鱼图标会变成粉色。这个面板就是她的完整对话：对话只在这里，各工作区的会话列表里看不到它。

直接告诉桃乐丝你要做什么，例如：

```text
在 D:\work\site 建个工作区，开一个任务：修好文档页里失效的链接，做完告诉我改了什么。
```

桃乐丝会：

- 新建或复用工作区，每个任务开一个会话，并写好完整的第一条指令。任务默认以「工作区写入」权限启动，常规审批由桃乐丝在后台处理；
- 按任务挑代理预设：一般的工作用 DSH 的默认预设；比较机械、主要靠脚本批量执行的工作用 `ptc`；写或改 DSH 插件、预设和设置的工作用 `cordis`。用 `cordis` 的任务能改动 DSH 本身，它和其他任务一样按「任务权限」启动，审批也走同样的路由；
- 不属于任何项目的事（查资料、打理 DSH 本身）开在她自己的工作区里。这个工作区在侧栏里叫 **Dorothy**，目录是 DSH 主目录下的 `dot` 文件夹，你也可以在里面开会话；
- 按你的要求给会话追加指令或停止它，你自己开的会话也可以交给她；也能按要求开始关注一个已有会话；
- 她自己开的会话，事情做完后她会自行归档。你开的会话她不能归档，即使她在关注它；这些请你自己在会话列表里归档；
- 审批、提问、出错和她自己开的任务结束一轮时及时汇报，时间相近的多条更新合成一条；她只是关注的会话结束一轮时先攒着，随她下一次唤醒或你的下一条消息一并带上，运行和空闲状态变化则记在看板里；
- 接管所有会话的审批弹窗和模型提问，包括你自己开的会话。常规请求和已在原会话处理的请求由她在后台静默收口，不在对话里刷屏；遇到删除项目外的数据、发布或推送、花钱、涉及凭据，或者改变方向和范围的请求，她会在对话里用卡片问你，再把你的答复转回去。她判断的依据是你写在「约定」里的规矩，加上「删除项目外数据、发布或推送、花钱、涉及凭据必须先经你同意」这条基本原则。

面板顶部的「任务」按钮展开看板：等你处理的请求，所有关注中的任务和它们的状态、最新进展，以及桃乐丝设的提醒；点一行任务即可打开对应会话。在底部输入框打字，Enter 发送，Shift+Enter 换行。桃乐丝工作时发的新消息会在她下一步时送达，「停止」结束她当前这一轮。

你可以让桃乐丝晚点或定期做一件事，例如「半小时后看看那个任务跑完没有」「每个工作日早上九点汇总一下进度」。她会给自己设一条提醒：只响一次（若干分钟后，或指定的日期和时间）、每隔若干分钟、每天固定时间，或一周里的某几天。到点时提醒会唤醒她，她照着当时写下的内容去做，再把值得你知道的告诉你。提醒属于桃乐丝，不属于某一段对话：对话换段后照常到点，重启 DSH 后仍然保留，DSH 没开期间错过的提醒在下次启动后补送一次。时间按运行 DSH 的那台电脑的本地时间计算，最多 50 条。看板的「提醒」里能看到每条提醒的周期和下次时间，点「移除」即可删除；也可以直接让她改或删。

和桃乐丝的对话可以一直聊下去。一轮结束后，如果上下文超过可用窗口的 70%，她会把对话换到新的一段：较短的上文原样带过去，较长的由她自己写一份交接笔记，再带上最近几轮原话和当时的任务台账。面板里仍是同一个连续的对话，换段的位置有一条分隔线，往上能看到最近六段的内容。改了她的模型或人设，或者隔了两小时以上再回来聊而上文已经不短，也会在你的下一条消息送达前换段。她正在工作时不换段；如果换段时聊天里还有未答复的卡片，卡片会继续生效，你的答复会自动送达新分段。

你也可以在她空闲时，直接在齿轮抽屉的「上下文」页点「开启新分段」。按钮不向桃乐丝发送消息，只沿用同样的交接流程，保留任务、提醒、约定、认知、未答卡片和可搜索的历史记录。她也能用自己的工具主动换段，在当前回合结束后生效。

换段不会丢掉之前说过的话。桃乐丝能搜索并原样读回以前的对话：她和你聊过的每一段，以及她派出或关注的任务会话。你提到她眼前已经没有的内容时，她会先去翻记录，再考虑请你重说。搜索按字面匹配，你说的几个词要出现在同一条消息里，所以用当时说过的词最容易找到。

另外，桃乐丝自己保留两份每次对话都该知道的东西。「约定」是你的：只有你明确说「记住……」或说出规矩时，她才按你的原话记下，你说要删时她才删，不额外找你确认。「认知」是她的：她对你的理解和你们协作方式的体会——她注意到什么、感受到什么、逐渐形成什么预期，有变化就整份重写。两份都在每一段对话开始时带进去，所以她刚写下的内容从下一段起才出现在她的提示词里，当前这一段她靠对话本身记得；两者冲突时一律以约定为准。发生过的事和任务细节不记在这里，需要时她去翻记录。

抽屉里的「轨迹」按轮次和步骤展示桃乐丝当前这一段的会话，和 DSH 自带的轨迹视图一样。每一轮显示步数、调用次数、耗时和 token；每一步显示模型、首字耗时、耗时和 token（含缓存命中部分）。步骤里按顺序列出你的消息、会话动态、她的思考、回复、工具调用（参数和结果）以及上下文压缩，点一行展开详情。最新一轮默认展开。搜索覆盖对话、工具名称、参数和结果里的文字；运行环境快照默认收起，勾选「显示环境快照」后出现。很长的记录显示开头部分，视图保留最近 30 轮。

### 设置

面板右上角的齿轮打开包含「设置 / 人设 / 上下文 / 轨迹」的抽屉，点右上角关闭或按 Esc 即可收起。选项切换即时保存；自由文本在离开输入框时自动保存。

| 设置 | 作用 |
| --- | --- |
| 桃乐丝的模型 | 日常对话、派发任务与审批把关共用的模型。「跟随默认模型」（默认）随宿主的默认模型变化。 |
| 接管范围 | 「所有会话」（默认），或「仅她跟进的任务」（只管她派出或关注的任务）。 |
| 权限审批 | 「桃乐丝管」（默认，常规放行、高风险问你）；「用户管」（每条审批转交你拍板）；或「一律不许」（自动拒绝所有审批请求）。 |
| 模型提问 | 「能答先答」（默认，目标明确的代答、涉及方向或范围变更再问你）；「一律转问我」；或「不接管」（交回各会话原生提问卡片）。 |
| 任务权限 | 新任务会话启动时用的权限档位：「工作区写入」（默认，可在工作区内写，越界时再申请）、「完全访问」（可动任何地方），或「跟随宿主」（用宿主自己的默认档位）。它与「权限审批」互相独立：权限档位管任务能碰到什么，审批方式管仍然弹出的请求由谁回答。 |
| 可用模型范围 | 「不限制」（默认）、「仅允许所选」或「排除所选」，支持按服务商分组筛选勾选。仅约束她派出的任务，不影响她自己的模型；她不指定模型时任务用宿主的默认模型，默认模型不在范围内时在可用模型里选一个，名单外的模型会被拒绝。 |

升级会保留你已保存的任务权限，包括「完全访问」和「跟随宿主」；只有未配置时才默认用「工作区写入」。旧的「全部放行」审批模式安全回退为「用户管」。旧补充规则迁入约定，旧笔记迁入认知，只导入一次。

「人设」页（人设与约定）管她怎么称呼你、日常语气与她的两份约定块。「对你的称呼」默认是「你」，填上名字、昵称或称谓后按 Enter 或离开输入框即保存。「性格与说话方式」里是她的默认人设文字，可以用中文或英文改写，点「保存修改」生效，「放弃改动」还原未保存内容。两项各有「恢复默认」。修改从你的下一条消息开始生效，对话会换到新的一段继续；无论人设怎么写，汇报、任务结果和审批判断都保持客观。

同一页里的「约定」就是你说的规矩，按原话记着，可以直接改：以「- 」开头的一行是一条，最多 4,000 个字符，点「保存修改」生效。「回退上次保存」把约定恢复到最近一次保存之前，不管那次是你改的还是她改的，只保留一步。

同一页里的「认知」是她自己的体会：她对你的偏好和你们协作节奏的判断，由她整份重写，你也能改，点「保存修改」生效。下面的「历史版本」留着最近十份旧文本，点「回到这一版」就能把其中一份恢复回来；每一份记的是它被替换下来的时刻。约定和认知都在她下一段对话开始时带进去，所以你在面板里的改动不会立刻进入她正在进行的这一轮对话。

同一抽屉里的「上下文」页显示桃乐丝当前这一段对话的上下文用量，打开期间自动刷新：她的模型窗口用了多少（新分段收到首条回复前先展示预设指令与交接内容的估算占用）、自动换段线的位置、压缩兜底线的位置（窗口的 90%，输出和预留空间需要时会更早；只有单独一轮就把窗口吃满时才会用到）、这一段已经压缩过几次，以及跨对话段持续统计的「累计用量」、缓存命中率与可随时重置起算的「清零」按钮。「提示词明细」把提示词分成系统提示词、工具定义、用户消息、注入内容、技能注入、助手消息和工具结果七类，依次展开分类和条目即可阅读文本或格式化 JSON；很长的条目显示开头部分。占用读取的是与对话输入框占用环相同的官方计量。「提示词分区」列出这一段对话实际带在提示词里的四块内容——人设、约定、认知和交接——照它们现在的样子显示，你能看到她当下真正依据的是什么。

桃乐丝可以读取自己的设置并申请修改。所有设置默认不锁定；点各标题右侧的锁图标即可锁定，锁只限制桃乐丝，不影响你自己的修改。未锁定的项目由她提交新值和理由，在设置的「待确认的修改」里等你「批准并应用」或「拒绝」。如果申请后你又改过该项目，批准不会覆盖你的新值，申请会保留供重新处理。锁和 `homeDir` 只能由你修改，待确认申请在重启后仍然保留。她也可以申请整份替换约定；约定加锁后，她日常的增删也需要同样经过你确认。

插件列表里保留两项设置：`homeDir` 是桃乐丝自己的工作区所在的目录，她自己的会话也在这里，留空使用 DSH 主目录下的 `dot` 文件夹；`approvalGraceMs` 是审批请求送到她面前的等待时间（毫秒），留出空档让原会话里的答复先结算（默认 10000）。

## 限制

- 桃乐丝通过其他会话干活：她的预设包含对话、上下文压缩、她自己的工具（含提醒）和几个查询工具，文件和终端工作交给任务会话。
- 她自己不查资料：查东西、读网页、跑命令都在任务会话里做，有记录可查。
- 她只能归档自己开的会话。
- 她翻记录只能翻到自己的对话和任务看板上的会话，其他会话搜不到。搜索是字面匹配，不理解同义词；默认只搜对话文字，工具调用和结果要她特意去搜。一次最多搜最近 120 个会话。
- 她的约定最多 4,000 个字符，单条最多 400 个字符；满了以后她要先删掉或合并旧的才能再记。认知最多 4,000 个字符，并保留最近十份历史版本。
- 约定是你的：只有你明确说「记住……」或说出规矩时，她才按你的原话记下；你说要删时她才删。认知是她的：她自己的理解变了就整份重写。两份你都能在「人设」页里改。
- 她的提醒只在看板里管理，不出现在 DSH 的「自动化任务」里。
- 她的面板显示文字、工具动态和 Deep View 卡片。附件和斜杠命令属于普通会话的功能。她的模型在设置里选。
- 权限审批和任务权限是两件事：完全访问的任务不会弹沙箱审批，也就没有可托管的请求。审批路由并不保证每个高风险操作都被拦下。
- 她放行的审批只对那一次请求有效，宿主不提供长期授权。
- 用 `cordis` 预设的任务和其他任务一样按「任务权限」启动，审批也走同样的路由。
- 任务用哪个预设由桃乐丝按任务内容判断，你也可以直接指定。预设要在这台 DSH 的预设列表里；`ptc` 和 `cordis` 是 DSH 自带的。
- 在会话自己的卡片上直接答复同样有效，以先到的答复为准。
- 等待中的请求和等待送达或攒着的通知保存在内存里，和宿主自己的待审批一样，重启 DSH 后清空。
- 审批、提问、报错和她自己开的任务结束一轮会唤醒桃乐丝跑一轮模型；攒着的更新随下一次唤醒或你的下一条消息送达，攒满一批也会合成一条发出。每条到点的提醒仍会唤醒她，同时到点的提醒合成一条。
- Windows 工作区沙箱内的测试和构建可能因为子进程无法启动而报 `spawn EPERM`。任务可以附上理由申请越界重试，桃乐丝会按你的约定和授权判断这一次具体操作。
- 「安全自动」可能先于桃乐丝结算审批：宽限期内结算就不唤醒她，通知送达后才结算则让她的迟到答复返回「已结算」，不再改变结果。审核超过宽限期时，仍可能与她的判断重叠。在网页界面里，「安全自动」要逐会话单独开启，新任务默认未开启；没有该界面时，全局审核可能覆盖她派出的任务，目前不能为这些任务单独豁免。选择「桃乐丝管」不会覆盖其他已生效的审批答复者。

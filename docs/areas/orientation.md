## What it is

DeepSeek Harness (`dsh`) is an open-source agent harness. It is built on an everything-is-a-plugin architecture powered by [Cordis](https://github.com/cordiverse/cordis). Product behavior is assembled from npm packages under `packages/`, each scoped `@deepseek-ai/dsh-*` and living in exactly one group. The group README is the package map for that family.

Official rendered docs: [https://deepseek-harness.github.io/deepseek-harness/](https://deepseek-harness.github.io/deepseek-harness/).

The project is in developer preview. The README states there will be compatibility-breaking changes. This index is pinned to one commit so a later upstream change does not silently rewrite these pages.

`docs/capability-seams.md` is generated by `scripts/gen-doc-graphs.ts`. A service can be a core spine service, a swappable capability seam, a bundle or composition point, or a standalone service. The graph names the package that owns the service declaration, known implementation packages, and packages that consume the service directly. The Service Definition / Service Provider / Consumer wording is spelled out on subsystem pages such as [docs/subsystems/subagent.md](https://github.com/deepseek-ai/deepseek-harness/blob/477b4f420553e8a52c2fbccc464d7561b239c443/docs/subsystems/subagent.md), not in the opening of the generated graph.

`packages/README.md` states the dependency rule for extension authors: extension plugins depend on Service Definitions, never concrete providers.

## How a plugin author uses it

1. Name the capability (tool, skill, preset, title, model route, MCP server, UI slot, hook bridge).
2. Open that area in this index, then open the cited official file at the pinned commit.
3. Prefer the package README's "Use this package" section and the generated [config catalog](other-seams.md) over copying a neighboring plugin.
4. Mount the Service Definition the host already provides. Ship a provider or a consumer, not a second copy of the seam.
5. When the official checkout and this index disagree, the pinned commit wins for this index, and the checkout you are actually running wins for behavior. Refresh this index rather than guessing.

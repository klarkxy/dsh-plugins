Pick a task, then read the linked area pages. Area pages stay the reference layer. These steps are written against dsh-v0.1.7-rc.2 (477b4f420553e8a52c2fbccc464d7561b239c443). If the target DSH version differs, treat every page as unverified for that version and check the pinned source and type declarations. Do not silently substitute this index.

Inside a running DSH, prefer the official cordis-plugin-development skill and cordis_inspect_query for what is actually mounted. Outside DSH, do not assume those tools exist. Context7 (/deepseek-ai/deepseek-harness) tracks master and is only a secondary source for scattered examples.

Read Architecture rules and anti-patterns before choosing a mechanism.
